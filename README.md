# Docker Deployment Portfolio
 
This repository contains the implementation work for **SWE40006 Software Deployment and Evolution** from Task 4.1 through Task 4.3.
 
## Objectives
 
- Configure and verify Docker on Windows.
- Build and run Docker containers.
- Develop and containerize Python Flask web applications.
- Publish Docker images to Docker Hub.
- Pull and run an image on a secondary Docker environment.
- Develop a custom web application for the Distinction level.
- Use an improved Dockerfile and exposed application ports.
- Verify container operation, logs, and lifecycle.
## Technologies
 
- Windows
- WSL2
- Docker Desktop
- Docker Engine
- Docker Hub
- Python
- Flask
- Gunicorn
- HTML and CSS
- Google Cloud Shell
- GitHub
